\# API



Python scripts that use the JSONPlaceholder REST API to gather employee TODO list data and export it.



\- `0-gather\_data\_from\_an\_API.py` - displays an employee's TODO list progress

\- `1-export\_to\_CSV.py` - exports an employee's tasks to `USER\_ID.csv`

\- `2-export\_to\_JSON.py` - exports an employee's tasks to `USER\_ID.json`

\- `3-dictionary\_of\_list\_of\_dictionaries.py` - exports all employees' tasks to `todo\_all\_employees.json`
